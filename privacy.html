Privacy notice

For Alfred Google Workspace, shown as gws CLI on the Google OAuth consent screen.

Purpose and responsibility

This is a personal-use assistant integration operated by the account owner, not a public service. Contact the operator at bergesassistant@gmail.com about access, correction, deletion or any privacy concern.

Data accessed and used

Depending on the requested task and the Google permissions granted, the integration can access email content, attachments, metadata, settings and filters; Drive files and metadata; Docs, Sheets, Slides and Forms content, including form responses; calendar and event information; contacts; and Google Tasks tasks and task lists. Google OAuth credentials are used to maintain the authorised API connection.

These data are used for the owner's requested email, document, file, scheduling, spreadsheet, presentation, form, contact-management and task-list assistance. Write permissions can allow composing, sending, editing, sharing or deleting data, maintaining contacts and tasks, and changing Gmail settings and filters; consequential actions require a specific owner instruction. The integration does not request permission for immediate permanent Gmail message deletion bypassing the trash.

Processing and sharing

The integration runs in the owner's assistant environment. For an AI-assisted task, relevant content may be included in the assistant's conversation and sent to the model provider configured by the owner for processing that task. Task results or selected information may also be retained in the owner's chosen memory or document tools. The provider and storage configuration can vary; contact the operator for the configuration relevant to a particular request.

Google user data are not sold, used for advertising or published on this website. The integration does not use Google user data to train or improve general-purpose AI or machine-learning models. Sending or sharing content with a recipient or another service requires an instruction covering that action.

Storage, retention and deletion

OAuth credentials are held in the owner's restricted runtime credential storage, not this website or its public repository. Relevant task content and results can persist in assistant conversation history, logs, backups or owner-selected storage. There is currently no single automatic deletion period across those systems; removing Google access does not automatically erase existing copies.

The owner can request deletion of retained content and credentials through the contact address. The operator will identify the relevant stores and any backup or provider retention limits when handling the request. This notice does not promise immediate erasure from third-party systems or backups.

Control and revocation

The account owner can withdraw future Google API access at any time in Google Account third-party connections. Revocation stops future authorised access; contact the operator separately to request deletion of already retained data.

This website

These are static information pages. They contain no sign-in form, analytics scripts, advertising, tracking pixels or application cookies. GitHub Pages hosts the site and may process technical request data such as IP addresses and browser information under the GitHub Privacy Statement. Do not send passwords, authorisation codes or tokens to the contact mailbox.

Google API Limited Use

Alfred Google Workspace's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
